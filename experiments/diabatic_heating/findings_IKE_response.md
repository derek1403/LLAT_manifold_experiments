# Findings:動能響應(ΔIKE)—— 加熱→動能是「延遲兩天、強度開關、幾乎全由水氣攜帶」

> **一句話**:先前所有響應指標都是 ΔPV。把同一批 run 換成 **ΔIKE**(與 Part-1 dashboard、
> 與 DeepTC_Radial-ai 訓練標籤同定義)之後,出現三件 ΔPV 看不到的事:
> (1) 動能響應**比 PV 響應晚約兩天** —— 注入期間完全沒有訊號,強迫停掉之後才起飛;
> (2) 起飛是**強度開關式**的 —— 同環境、同加熱,0920 幾乎不動(+0.97 TJ),0921 到 +6.67 TJ;
> (3) 起飛**幾乎完全由水氣攜帶** —— 鎖 q 只剩 **3%**(+6.67 → +0.22 TJ),而且
> **純 δq(完全不加熱)產生的動能是「加熱但鎖 q」的十倍**。
>
> 也就是說:**ΔPV 的「鎖 q 還剩四到六成」在動能上不成立,動能的綁定緊得多。**
>

## 1. 為什麼要換指標

$\mathrm{IKE} = \tfrac12\rho\int V_t^2\,\mathrm{d}V$(方位平均 10 m 切向風、5 km 環積分)是
**外圍**量,由外圍風場主導,不是巔峰風速。平衡渦旋理論裡它由次級環流的角動量重分配堆出來,
而次級環流由非絕熱加熱驅動 —— 所以「模式怎麼把加熱換成動能、換到哪裡去」才是 IKE 問題本身。
ΔPV 回答的是「有沒有在該生成渦度的地方生成渦度」,不是這件事。

ΔIKE 用 `diagnostics/ike.py`,它逐字重用 Part-1 的 `regional_couple.diagnostics.ike`,
所以這裡的數字與作業 dashboard、與 DeepTC_Radial-ai 的標籤**是同一個量**,可以直接對照。

## 3. 三個發現

### (1) 動能落後 PV 約兩天

注入期間(h0–24)所有家族的 ΔIKE 都在 ±0.7 TJ 內、正負亂跳 —— **沒有訊號**。
同一時間 ΔPV 偶極已經完全長出來。起飛發生在 h50–60 之後,也就是**強迫早就停掉之後**。

這與平衡渦旋理論一致(加熱先造 PV,平衡調整才把風場轉起來),但有一個很實際的後果:
**不能從 PV 響應讀出 IKE 響應,兩者不同時鐘。** 這是 ΔPV 診斷完全看不到的資訊。

### (2) 起飛是強度開關,不是連續增益

0920 基本上不起飛(+0.97 TJ ≈ 控制場的 1%),0921 到 +6.67 TJ(數個 %,曲線在 h105
附近尖到約 +12 TJ)。**同環境、同加熱、同注入,只有渦旋不同。**

### (3) 綁定在動能上比在 PV 上緊得多

| | ΔPV 鎖 q 存活率 | **ΔIKE 鎖 q 存活率** |
| --- | ---: | ---: |
| 0920 | 59% | **−22%**(+0.97 → −0.21) |
| 0921 | 38% | **3%**(+6.67 → +0.22) |

鎖 q 之後 PV 還剩 38–59%,動能**幾乎不剩**,0920 甚至翻負。逆探針從另一側說同一件事,
而且更刺眼:**純 δq、$\dot\theta=0$、完全不加熱,在 0921 給出 +2.34 TJ —— 是「加熱但鎖 q」
(+0.22)的十倍。** 在這個模式裡、對這個量而言,**只給水氣比只給熱有效得多。**

### 附帶:rollover 在動能上更尖銳

ΔPV 低層:+0.450 → +0.848 → +0.462(0922 保住 0921 的 55%)。
ΔIKE:+0.97 → +6.67 → **+1.44**(0922 只保住不到 1/4)。逆探針同向塌
(+1.84 → +2.34 → +0.22)。**但 caveat 不變**:σ 固定而 RMW 收縮到 120 km,
內在效率翻轉與加熱尺度不匹配**未分離**(見 [`report_intensity_ladder_zh.md`](report_intensity_ladder_zh.md))。

## 4. 誠實判讀

1. **絕對量很小**。+6.67 TJ 對上控制場 87–123 TJ 只有數個 %。結論靠的是
   **moist 與 qlock 之間的落差**(+6.67 vs +0.22),那個落差比逐步震盪大一個量級。
2. **只引用視窗平均,不引用單一 lead**。曲線相鄰步之間可以差好幾 TJ。
3. **注入期間的正負跳動是雜訊,不是結果**。這個診斷不是為了解析次 TJ 訊號設計的,
   不要為那段編機制。
4. **0917 不進主論述**。它在自身(弱)環境,SST/陸地/緯度都不同,post-forcing 給
   −5.48 TJ 很有趣但confounded,不能讀成「最弱的渦旋會掉動能」。
5. 沿用全系列限制:單一颱風、單一 heat_type(Deep)、單一注入時長、$n\times3$ h ≠ 物理時間、
   軸對稱只在 $n=0$ 嚴格成立。

## 5. 可重現性

```bash
PY=/home/pc/.conda/envs/pangu_env/bin/python
cd experiments/diabatic_heating/src

# 首次:9 個 (family, init) 平行計算,約 10 分鐘,結果快取到 figs/axisym/ike/_i1_series_cache.npz
$PY fig_I1_ike_ladder.py --ic axisym --with-0917 --recompute

# 之後重畫:約 2 秒(讀快取)
$PY fig_I1_ike_ladder.py --ic axisym              # --no-vsev 只留 0920/0921
```

每個 `_ike_profile` 呼叫約 5 s(Part-1 的極座標轉換,**刻意逐字重用、不優化**),
整張圖需要約 1,300 次 —— 所以有快取。**任何 run 重跑之後要 `--recompute` 或刪快取。**

## 第 0 幕(基礎):我們到底在做什麼

> 這一幕是 v2 新增的。v1 直接從假說開始,對已經在脈絡裡的人沒問題,但對第一次看的人
> 少了四塊地基。四張圖依序回答:注入什麼 → 怎麼量 → 場長什麼樣 → PV 怎麼長出來。

### B1 注入了什麼

![B1 注入內容](figs/axisym/p95/b1_what_was_injected.png)

每一個加熱 run 加進溫度場的都是同一個形狀,只差一個振幅 `amp_K`:

$$\Delta T(p,x,y) = \frac{\text{amp\_K}}{8}\; V(p)\; e^{-r^2/2\sigma^2}
\qquad \text{每步一次,共 8 步}$$

- (a) 垂直權重 $V(p)$:Deep 剖面,半正弦,1000 與 200 hPa 為零,峰在 **600 hPa**。
- (b) 水平足跡:高斯,$\sigma = 5$ 格 = **139 km**;**$2\sigma$ = 278 km 就是後面所有
  診斷取平均的「核心」**。
- (c) 兩者相乘 = 模式真正收到的東西,5 K run 是 **0.625 K/step**。
- (d) 時程:前 24 h 注入,之後**完全不再加任何東西**,全是自由演化。

圖直接呼叫 driver 用的同一組函式(`vertical_profile` / `gaussian_centered`),
所以它就是強迫本身,不是重畫。

### B4 怎麼量:兩條軌跡、一個相減、一個約束

![B4 方法示意](figs/axisym/p95/b4_method_schematic.png)

- (a) **兩條軌跡**:同一個模式運算子 $M$(一步 = 3 h DLAMPty)同時推進 control 與
  perturbed,強迫 $f$ 只加在 perturbed 那條;每步相減得 $\delta_n = A_n - I_n$。
  **報告裡的一切都是 $\delta$。** 每步相減把模式自身的漂移、日夜循環、颱風自己的移動
  都消掉了 —— 兩條軌跡一起做的事會抵銷。
- (b) **一個約束**:所謂「$\delta q = 0$」的 run,就是同一個迴圈多一行:每步之後把
  $\delta$ 的水氣分量歸零,所以 perturbed 下一步帶著 control 的水氣進去。
  **沒有從物理裡拿掉任何東西** —— 模式對水氣照做它會做的事;被拿掉的是
  擾動在那一個通道上**「可以不一樣」的自由度**。活下來的響應,就是不需要水氣共同演化的那部分。
- (c) **收斂成一個數**:核心內的 ΔPV 場壓成每極一個純量,那就是後面每張掃描圖的 y 值。

### B2 純加熱 → PV 怎麼長出來

![B2 PV 空間演變](figs/axisym/p95/b2_pv_evolution.png)

這是 v1 完全沒揭露、但其實最該先看的一張:**不壓縮成一個數字的響應本身**。
上列加熱、下列同名義振幅的 δq-only,橫軸是 lead,同一個色階。

三件事直接用眼睛就能讀:

1. **前 24 h(橘色欄標題,強迫還在進行)**:軸上長出一根正 PV 柱。
   值得注意的是它**不侷限在 600 hPa 加熱峰之下**,而是整層貫穿 —— 這與教科書
   「生成在加熱峰下、破壞在其上」的乾式圖像並不完全吻合。
2. **24 h 之後不再注入任何東西**,正 PV 柱仍撐滿五天。
3. **高層(200–300 hPa)的負瓣是遲到的**,軸對稱組約 $n \approx 72$–96 h 明顯挖深
   (真實 IC 更晚,$n \approx 96$–120 h,見 [`figs/ragasa/p95/b2_pv_evolution.png`](figs/ragasa/p95/b2_pv_evolution.png))。
   **偶極的「破壞」那一半不是瞬時平衡響應,是強迫停掉很久以後模式自己長出來的。**
   兩組 IC 都遲到,但軸對稱場早了約一天 —— 與第 10 幕「真實個案的不對稱外流把高層響應
   分散掉、軸對稱渦旋把它集中」的待驗假說方向一致。

下列的 δq-only:**同樣的結構,較弱,但絕對不是空白**。這一格不需要任何指標就是整個
反向探針論證本身。

## 第 0.5 幕:為什麼把極值換成百分位

> 教授的意見是極值跳動太大。這一幕把「跳動」變成可查的數字,並說明換掉之後
> 哪些結論更穩、哪些其實沒差。

**只換 reduction,不換別的**:取樣母體完全相同(核心 $r \le 2\sigma$ × 該極的氣壓帶,
低層 4 層 × 317 格 = **1268 個點**)。

- `max` = 那 1268 點的極值 —— **一格決定整條曲線**。
- `p95` = **前 5% 的平均**,即 $\overline{\{x : x \ge Q_{95}\}}$,約 **63 格一起投票**。
- `p90` = **前 10% 的平均**,約 **127 格**。

> ⚠️ **百分位只是「切在哪」,報出來的值是切點以外那條尾巴的平均**,不是百分位值本身。
> 這正是重點:平均不會被單一格點拉走,極值會。程式裡對應
> `_reduce()` 的 `value = dpv[sel].mean()`。
> 三者有序:$\text{p90} \le \text{p95} \le \max$。

![S0 統計量比較(低層)](figs/axisym/p95/s0_stat_comparison_lowlevel.png)
![S0 統計量比較(高層)](figs/axisym/p95/s0_stat_comparison_upperlevel.png)

> ⚠️ **軸對稱強颱低層那格的 $J_{\max}=0$ 不是「極值很穩」,是退化。** 20 個振幅的 argmax
> 全部落在**同一個模式層**,一個相異值,所以二階差分恆為零 —— 這是同一個離散化病灶
> 的極端形式(高層同組是 55.6 hPa,在兩層之間來回跳)。尾巴質心給的 1.6 / 1.9 hPa 才是
> 有資訊量的連續量。

**結論,分三層** ——

1. **值的抖動:全面改善 2–6 倍。** 而且**相對抖動 $J_{\rm rel}$ 也同步下降**
   (強颱低層 0.006 → 0.003;高層 0.009 → 0.003),因為尾巴平均在量值上接近極值
   (0.416 vs 0.649 PVU),沒有「數值變小所以看起來比較平」的尺度假象。
2. **5 天序列同樣改善 2.2–3.8 倍**,$J_{\rm rel}$ 真實 IC 從 0.22–0.24 降到 0.14–0.18、
   軸對稱 IC 從 0.23–0.38 降到 0.19–0.23。**軸對稱組的序列本來就更抖**(去掉不對稱環境
   之後響應更大、更集中),換統計量的收益因此更明顯。
3. **改善最大的是「位置」,而這正是 v1 第 1 幕拿來講故事的東西。**
   極值所在層的抖動是 **25 hPa**(軸對稱組高層更達 **55.6 hPa**),因為 argmax 那一格在
   2–3 個離散模式層之間**跳**:20 個振幅只掃出 **1–3 個**相異氣壓值,所以
   「極值隨振幅走進核心(925→700 hPa)」讀起來是階梯而不是趨勢。
   同一個病灶的另一面是軸對稱強颱低層的 $J_{\max}=0$(20 個振幅只有 **1 個**相異值,
   曲線是一條水平線,沒有任何訊息)。尾巴平均的**加權質心**抖動只有 0.6–6.4 hPa,
   20 個振幅給出 **20 個**相異值,是連續移動的曲線。

> **主軸採 p95,p90 為對照。** 兩者都遠優於極值;p90 一律更平滑(多一倍格點投票),
> 代價是取樣範圍向外擴、離「響應核心」較遠。最終取捨等軸對稱組的數字出來再定,
> 若 p90 沒有明顯犧牲物理解析度,就用 p90。
> **位置語意與極值不同**:報的是尾巴的 $|\Delta \mathrm{PV}|$ 加權質心 ——
> 「前 5% 的區域重心在哪」,不是「最大的那一格在哪」,兩者不可混用比較。

## 限制(v2 新增兩條)

1. **軸對稱只在 $n = 0$ 嚴格成立。** `sfc[9:]`(SST/科氏/地形/海陸)保留真實值,
   下邊界不對稱,B3 第三列量化了它把對稱破壞得多快。所有基於軸對稱組的宣稱都必須
   活在那個視窗內。0920 尤其嚴重(6.45% 陸地、地形 1890 m)。
2. **百分位的「位置」與極值語意不同。** p95 的 `_p` / `_r` 是超越集的加權質心,
   回答「前 5% 的區域重心在哪」;極值的是「最強的那一格在哪」。
   兩者不可混用比較。
3. (沿用 v1)綁定是**通路別**的;單一颱風兩階段、單一加熱型;
   $n \times 3\,$h ≠ 物理時間。

## 可重現性

```bash
# 1. 建軸對稱 IC(純 numpy,不載模式權重以外的東西)
python scripts/make_axisymmetric_ic.py --tc-id 202518W --inits 2025091700 2025092000

# 2. 全套 run(分三階段,階段 2 有相依:dq 定標必須量在階段 1 之後)
bash scripts/run_axisym_batch.sh          # 或 run_axisym_batch.sh 1 / 2 / 3

# 3. 圖(--ic {ragasa,axisym} × --stat {max,p95,p90})
cd experiments/diabatic_heating/src
for f in fig_*.py; do python $f --ic axisym --stat p95; done

# 4. 數字(報告裡每個數都能在這份 CSV 找到對應列)
python scripts/export_metrics.py --ic axisym ragasa --out outputs/response_metrics.csv
```
